# Multi-Agent Security Scanner

**MAS** est une plateforme d'analyse de sécurité de code source pilotée par des agents IA. Elle combine analyse statique multi-outils, raisonnement LLM, génération automatique de correctifs et mémoire persistante.

## Ce que le projet fait

<Steps>
  <Step title="Triage">
    Détection automatique des langages (Python, JS, C/C++, Go, Java, PHP, Rust…) et construction des cibles de scan.
  </Step>
  <Step title="Analyse statique">
    Lancement parallèle de **Semgrep**, **Bandit**, **Gosec**, **SpotBugs** et **PHPCS** avec cache intelligent.
  </Step>
  <Step title="Analyse LLM">
    Détection des failles logiques (auth bypass, IDOR, race conditions) via un LLM 70B augmenté de RAG Qdrant.
  </Step>
  <Step title="Scoring CVSS">
    Chaque vulnérabilité reçoit un score CVSS 3.1 et un booléen d'exploitabilité calculés par LLM.
  </Step>
  <Step title="Patching automatique">
    Génération de diffs unifiés pour toutes les vulnérabilités exploitables (CVSS ≥ 7.0).
  </Step>
  <Step title="Validation">
    Application du patch, re-scan Semgrep, détection de régressions. Retry automatique (max 3 itérations).
  </Step>
  <Step title="Rapport">
    Rapport JSON structuré avec statistiques, top CWEs, détail des vulnérabilités et état des patches.
  </Step>
</Steps>

## Fichiers clés

| Fichier | Rôle |
|---------|------|
| `src/api.py` | Application FastAPI — 20+ endpoints, lifespan, background tasks |
| `src/graph/workflow.py` | Construction du graphe LangGraph |
| `src/graph/state.py` | `AgentState`, `Vulnerability`, `ScanTarget`, enums |
| `src/agents/*.py` | 8 agents spécialisés |
| `src/tools/*.py` | Wrappers Semgrep, Bandit, Gosec, SpotBugs, PHPCS |
| `src/memory/persistent.py` | Qdrant + Sentence Transformers |
| `src/llm/client.py` | Clients Groq et NVIDIA |
| `src/github_client.py` | Clone, gestion et nettoyage de dépôts GitHub |
| `src/mcp_server.py` | Serveur MCP JSON-RPC 2.0 |
