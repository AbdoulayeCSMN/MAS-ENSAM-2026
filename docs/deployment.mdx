## Documentation Mintlify

### Option A — Mintlify Cloud (recommandé, gratuit)

<Steps>
  <Step title="Créer un compte Mintlify">
    Rendez-vous sur [mintlify.com](https://mintlify.com) et connectez-vous avec GitHub.
  </Step>
  <Step title="Installer l'app GitHub">
    Dans le dashboard Mintlify → **Add Project** → autoriser l'accès à votre dépôt `MAS-ENSAM-2026`.
  </Step>
  <Step title="Configurer le projet">
    Mintlify détecte automatiquement `docs.json` à la racine.

    ```
    Root directory    : /
    Config file       : docs.json
    Docs directory    : docs/
    ```
  </Step>
  <Step title="Déployer">
    Cliquez **Deploy**. Votre documentation est disponible sur :

    ```
    https://votre-projet.mintlify.app
    ```

    Chaque `git push` sur la branche principale redéploie automatiquement.
  </Step>
</Steps>

<Info>
  Le plan gratuit Mintlify inclut un domaine `.mintlify.app`, le déploiement continu depuis GitHub et la recherche IA intégrée.
</Info>

### Option B — Domaine personnalisé

Dans le dashboard Mintlify → **Settings → Custom Domain** :

```
docs.votre-domaine.com  →  CNAME  →  custom.mintlify.app
```

### Prévisualisation locale

```bash
# Installer Mintlify CLI
npm install -g mintlify

# Lancer en local
npx mintlify dev

# Disponible sur
http://localhost:3000
```

## API + Interface

### Option A — Railway (recommandé, gratuit tier)

<Steps>
  <Step title="Créer un compte Railway">
    Rendez-vous sur [railway.app](https://railway.app) et connectez-vous avec GitHub.
  </Step>
  <Step title="Nouveau projet depuis GitHub">
    **New Project → Deploy from GitHub repo** → sélectionnez `MAS-ENSAM-2026`.
  </Step>
  <Step title="Configurer les variables d'environnement">
    Dans Railway → **Variables** :

    ```env
    GROQ_API_KEY=gsk_xxxxxxxx
    NVIDIA_API_KEY=nvapi_xxxxxxxx
    GITHUB_TOKEN=ghp_xxxxxxxx
    PORT=8000
    ```
  </Step>
  <Step title="Configurer la commande de démarrage">
    Dans Railway → **Settings → Deploy** :

    ```bash
    python -c "import sys; sys.path.insert(0, 'src'); from api import app; import uvicorn; uvicorn.run(app, host='0.0.0.0', port=8000)"
    ```
  </Step>
  <Step title="Accéder à l'application">
    Railway génère une URL :

    ```
    https://mas-scanner-production.up.railway.app
    https://mas-scanner-production.up.railway.app/ui
    https://mas-scanner-production.up.railway.app/docs
    ```
  </Step>
</Steps>

### Option B — Render (gratuit avec limitations)

<Steps>
  <Step title="Créer un Web Service">
    Sur [render.com](https://render.com) → **New Web Service** → connectez votre repo GitHub.
  </Step>
  <Step title="Configuration">
    ```
    Runtime         : Python 3
    Build Command   : pip install -r requirements.txt
    Start Command   : python -c "import sys; sys.path.insert(0, 'src'); from api import app; import uvicorn; uvicorn.run(app, host='0.0.0.0', port=8000)"
    ```
  </Step>
  <Step title="Variables d'environnement">
    Dans **Environment** → ajoutez `GROQ_API_KEY`, `NVIDIA_API_KEY`, `GITHUB_TOKEN`.
  </Step>
</Steps>

<Warning>
  Le plan gratuit Render met l'instance en veille après 15 min d'inactivité. Le premier scan après une veille peut prendre 30–60 secondes.
</Warning>

### Option C — Docker (auto-hébergé)

Créez `Dockerfile` à la racine :

```dockerfile
FROM python:3.11-slim

WORKDIR /app

# Dépendances système
RUN apt-get update && apt-get install -y git patch && rm -rf /var/lib/apt/lists/*

# Dépendances Python
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

# Code source
COPY src/ ./src/
COPY memory-engine/target/release/memory-engine* ./memory-engine/target/release/

# Lancement
EXPOSE 8000
CMD ["python", "-c", "import sys; sys.path.insert(0, 'src'); from api import app; import uvicorn; uvicorn.run(app, host='0.0.0.0', port=8000)"]
```

```bash
# Build
docker build -t mas-scanner .

# Run
docker run -p 8000:8000 \
  -e GROQ_API_KEY=gsk_xxx \
  -e NVIDIA_API_KEY=nvapi_xxx \
  mas-scanner
```

Avec Qdrant :

```yaml
# docker-compose.yml
services:
  api:
    build: .
    ports:
      - "8000:8000"
    environment:
      - GROQ_API_KEY=${GROQ_API_KEY}
      - NVIDIA_API_KEY=${NVIDIA_API_KEY}
      - QDRANT_HOST=qdrant
      - QDRANT_PORT=6333
    depends_on:
      - qdrant

  qdrant:
    image: qdrant/qdrant
    ports:
      - "6333:6333"
    volumes:
      - qdrant_data:/qdrant/storage

volumes:
  qdrant_data:
```

```bash
docker compose up -d
```
